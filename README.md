## Shift Scheduler
Horizontal implementation for the project
1. Will start by implementing the login page: user will have the option to choose between admin or student and it will be stored in the cookies to prevent unrestricted access to pages
2. The buttons will redirect to corresponding pages
3. The Student Scheduler shows weekdays as rows and time as columns in 10-minute increments, with hourly headers. Students can click or drag across the grid to select or clear availability, choose part-time (3–20 hours/week) or full-time (20–40 hours/week), review daily and weekly totals, and submit it using JSON fetch. The Go server validates the employment type, weekly limits, 3-hour minimum contiguous availability blocks, and 9-hour daily maximum. Submitted availability remains visible on the student page, along with pending, approved, or denied status; HTMX refreshes pending status, and denied submissions show the admin's reason and can be edited and resubmitted.
4. The admin approval page displays each submitted student schedule, requested work type, submission time, total hours, and daily availability ranges. Admins can approve or deny pending submissions and must provide a reason when denying. Decisions and denial reasons remain visible on both pages while the server is running. Submissions are currently held in memory and do not survive a server restart.
5. After a denial, students can revise the saved availability and submit a replacement schedule for a new review.
